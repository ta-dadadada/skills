# just-do-it

Complete an explicitly requested task directly, with the main agent executing
by default and no optional skill discovery. Independent parallel work is
allowed only when permitted and expected to shorten time to the verified
deliverable, including coordination and integration costs.

## Use

Explicitly invoke `just-do-it` alongside the task, or ask to work without
additional skills. The mode applies to the current task. Required checks,
authority boundaries, and limits such as design-only requests still apply.
Explicit-only activation is an instruction in the portable skill, not a
tool-enforced activation setting.

## Install

```bash
npx skills add ta-dadadada/skills --skill just-do-it
```

```bash
apm install ta-dadadada/skills/meta/just-do-it
```
